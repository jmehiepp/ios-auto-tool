# Third-party components

The core daemon includes Mongoose 7.14 (Cesanta, GPL version 2 distribution option) and a pinned LuaJIT 2.1 build (MIT license). Their source and notices are retained; the package contains license texts under `Library/IOSAutoTool/licenses`.

Mongoose upstream: https://github.com/cesanta/mongoose/tree/7.14

LuaJIT source revision: `c4b1e2f73a2e10fbcc637fcec474f639c38daafe`, https://github.com/LuaJIT/LuaJIT

Theos is the build system: https://github.com/theos/theos

This core release distributes its corresponding source in this repository. It does not redistribute the iOSAutomate binaries, recovered UI, or decompiled code from the separate research workspace.
