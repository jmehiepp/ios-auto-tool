Cài đặt

  1. Thêm URL nguồn vào Sileo.
  2. Tìm iOS Auto Tool và cài gói phù hợp Rootful, Rootless hoặc RootHide.
  3. Lấy mã kết nối trên thiết bị theo hướng dẫn, rồi mở http://IP-IPHONE:8890.

Đã thử tap, Home, screenshot/OCR, MJPEG, Lua, profile và widget chọn/chạy/dừng trên iPhone 6s/iOS 15.8.4/RootHide. Beta 4 sửa timeout widget khi hệ thống chậm; gồm giữ script của ứng dụng trong Device WebKit và CLI chạy Lua. Cấu hình đã có phép thử đối chứng; chưa tương đương toàn bộ iOSAutomate hay script cũ.
